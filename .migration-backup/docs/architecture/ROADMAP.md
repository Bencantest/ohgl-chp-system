# Roadmap

## Completed

- OCHP-001 Identity & Access
- OCHP-002A Referral Foundation
- OCHP-002B Workflow Command Engine
- OCHP-002C Workflow UI Integration

## Planned

### OCHP-002C.1 Workflow Metadata Engine

Move workflow action presentation, input definitions, reference data, confirmations, and validation messages to backend metadata.

### OCHP-002D Clinical Operations

Expand clinical worklists, consultation experiences, and operational clinical task handling.

### OCHP-003 Laboratory Module

Lab orders, specimen tracking, results, and result acknowledgement.

### OCHP-004 Radiology Module

Imaging requests, scheduling, reports, and attachments.

### OCHP-005 Pharmacy Module

Medication orders, dispensing, stock checks, and pharmacy workflow.

### OCHP-006 Inpatient Module

Admission, bed management, ward rounds, and discharge planning.

### OCHP-007 Analytics & Dashboards

Operational dashboards, SLA analytics, facility performance, and county-level reporting.

### OCHP-008 External Integrations

FHIR, SHA, DHIS2, laboratory systems, radiology systems, pharmacy systems, and notification providers.

### OCHP-009 Mobile CHP Application

Offline-capable mobile workflows for community referral creation and follow-up.

### OCHP-010 Multi-Tenant County Deployment

County-level tenancy, facility grouping, administrative scopes, and deployment automation.

## Roadmap Principles

- Protect patient data.
- Preserve auditability.
- Keep workflow rules backend-owned.
- Design integration boundaries before direct integrations.
- Maintain backward compatibility until consumers are migrated.
