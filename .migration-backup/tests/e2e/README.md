# End-to-End Test Template

Recommended future tool: Playwright.

Core browser journeys:

- Login and logout.
- Register pending user.
- Approve user as super admin.
- Create referral as CHP.
- Progress referral as facility user through metadata-driven workflow actions.
- Confirm dashboards, reports, and tracker still render.

Accessibility checks should include keyboard navigation, focus states, labels, and contrast.
