# Documentation

This folder contains operational and architecture documentation for the Oasis Community Health Platform (OCHP).

## Structure

- `architecture/` - system architecture, domain model, roadmap, and contribution guidance.
- `adr/` - Architecture Decision Records for major implemented and planned decisions.
- `api/` - public RPC and frontend/backend API contracts.
- `database/` - database and migration guidelines.
- `security/` - authentication, authorization, RLS, and threat model documentation.
- `workflows/` - healthcare workflow and referral workflow documentation.

Existing operational documents remain at the top level for deployment, production readiness, migrations, and testing.
