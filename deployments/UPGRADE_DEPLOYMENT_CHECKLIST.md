# Upgrade Deployment Checklist

## Planning

- [ ] Scope frozen.
- [ ] Release notes drafted.
- [ ] Migration diff reviewed.
- [ ] Staging deployment scheduled.
- [ ] Production window approved.
- [ ] Rollback owner assigned.

## Staging

- [ ] CI green on release candidate.
- [ ] Migrations applied to staging.
- [ ] Frontend deployed to staging.
- [ ] Smoke tests passed.
- [ ] Monitoring checked for errors.

## Production

- [ ] Backup verified.
- [ ] Stakeholders notified.
- [ ] Migrations applied.
- [ ] Frontend deployed.
- [ ] Post-deployment checklist completed.
- [ ] Release tag created or confirmed.

## Closeout

- [ ] Release notes published.
- [ ] Incident watch period completed.
- [ ] Known issues documented.
